# Jabat Tangan Elektron — video Teori Ikatan Valensi

Film edukasi **Teori Ikatan Valensi** (Kimia Kuantum S1 Kimia UNESA, RPS pertemuan 9), dibuat dengan [Remotion](https://remotion.dev). ±14 menit, 22 adegan, 2K 30 FPS, subtitle kata-per-kata.

Isi: pasangan Lewis → kurva energi H₂ → Heitler–London → efek pertukaran → pasangan spin (singlet) → struktur ionik & resonansi → tumpang tindih σ/π → teka-teki karbon & promosi → sp³, sp², sp → pasangan bebas (NH₃, H₂O) → meramal bentuk → resonansi benzena → intan/grafit/grafena → plastik penghantar → kegagalan O₂ paramagnetik (menuju orbital molekul).
